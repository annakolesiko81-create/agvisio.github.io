1Обрабатываемые персональные данные

Оператором могут обрабатываться следующие данные:

  • Фамилия, имя, отчество

Данные предоставляются пользователем путём заполнения форм на страницах сайта agvisio.ru.

2Ответственность пользователя

Пользователь отвечает за достоверность предоставленных данных и самостоятельно несёт риски при предоставлении чужих или недостоверных сведений.

3Цели обработки

Персональные данные обрабатываются в целях: предоставления демо-доступа к системе AgVisio; подготовки индивидуального расчёта окупаемости; направления коммерческого предложения; информирования о продуктах ООО «Инлайн» (с согласия пользователя).

4Принятие условий

Оператор обрабатывает данные только после их отправки пользователем через форму. Отправка формы означает согласие с настоящими Условиями.

5Обезличенные данные

Оператор обрабатывает обезличенные данные (cookie, данные аналитики) при наличии соответствующих настроек браузера пользователя.

6Виды обработки

С персональными данными выполняются следующие действия:

  • Сбор и запись
  • Систематизация и хранение
  • Использование в целях, указанных в п. 3
  • Удаление по истечении срока или по заявлению пользователя

Обработка осуществляется с использованием средств автоматизации.

7Передача третьим лицам

Персональные данные не передаются третьим лицам ни при каких условиях, за исключением случаев, предусмотренных действующим законодательством РФ.

8Хранение данных на территории РФ

Все персональные данные граждан РФ хранятся и обрабатываются с использованием баз данных, расположенных на территории Российской Федерации (ст. 18.1 № 152-ФЗ).

9Трансграничная передача

Оператор не осуществляет трансграничной передачи персональных данных.

10Срок обработки и отзыв согласия

Срок обработки персональных данных — до момента отзыва согласия пользователем. Для отзыва согласия направьте письменное заявление на адрес Оператора. С момента отзыва использование сайта в части интерактивных сервисов может быть ограничено.

11Изменения в условиях

Оператор вправе вносить изменения в настоящие Условия. Актуальная версия размещена по адресу agvisio.ru/personal-data.html. При существенных изменениях пользователь может быть уведомлён по указанному e-mail.
